The World in One Day — a broadsheet front page that sums up the world news of Friday, 20 November 2026 in a single 1024 × 1024 image. `render.py` typesets and draws the whole page in code with Pillow from a fixed news brief: banner lead, labelled Bay of Bengal cyclone map, illustrated stories, world map with pins, and a date check — no downloaded assets, fully deterministic. The graded entrypoint `main.ts` uses only the Node standard library: it copies the committed `entry.png` into the output directory.

## Run it

```sh
node main.ts
```
